## 🛠️ How to Create a Worksheet

### Step 1: Copy Template (2 min)
```
Copy: worksheet-template-new.html
To:   ws_topic_name.html
```

### Step 2: Customize Content (45 min)
Edit these 6 sections:
1. **Topic Name** - What you're teaching
2. **Learning Objectives** - 4-5 clear goals
3. **Practice Scenario** - Real-world example
4. **Screenshot** - Visual guidance (image)
5. **Hints** - 3-5 helpful tips
6. **Sample Solution** - Working code example

### Step 3: Test (15 min)
- [ ] Test on desktop (Chrome, Firefox)
- [ ] Test on mobile (iPhone, Android)
- [ ] Verify all links work
- [ ] Check for spelling/grammar

### Step 4: Deploy (5 min)
- [ ] Upload to server
- [ ] Test live version
- [ ] Share with students

**Total Time: ~70 minutes per worksheet**
